
# Raw Copper

This recipe allows you to obtain Raw Copper by crushing Copper Ore using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| ![Copper Ore](@minecraft:item/copper_ore) 1x Copper Ore | ![Raw Copper](@minecraft:item/raw_copper) 1x Raw Copper |
| | ![Raw Copper](@minecraft:item/raw_copper) 2x Raw Copper (10% chance) |

## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Copper Ore
- **Main Output:** 1x Raw Copper
- **Bonus Output:** 2x Raw Copper (10% chance)
- **Processing Time:** 200 ticks (10 seconds)
