
# Raw Zinc

This recipe allows you to obtain Raw Zinc by crushing Zinc Ore using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| 1x Zinc Ore | 1x Raw Zinc |
| | 2x Raw Zinc (10% chance) |

## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Zinc Ore
- **Main Output:** 1x Raw Zinc
- **Bonus Output:** 2x Raw Zinc (10% chance)
- **Processing Time:** 200 ticks (10 seconds)
