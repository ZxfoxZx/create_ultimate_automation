
# Raw Iron

This recipe allows you to obtain Raw Iron by crushing Iron Ore using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| ![Iron Ore](@minecraft:item/iron_ore){item} 1x Iron Ore | ![Raw Iron](@minecraft:item/raw_iron){item} 1x Raw Iron |
| | ![Raw Iron](@minecraft:item/raw_iron){item} 2x Raw Iron (10% chance) |

## Processing Method

![Crushing Wheels](@create:item/crushing_wheel){item}

This recipe is processed using Create's Crushing Wheels.

Place the required ingredient into the Crushing Wheels to process it into the resulting material.


## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Iron Ore
- **Main Output:** 1x Raw Iron
- **Bonus Output:** 2x Raw Iron (10% chance)
- **Processing Time:** 200 ticks (10 seconds)
