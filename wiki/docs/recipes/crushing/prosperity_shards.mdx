
# Prosperity Shards

This recipe allows you to obtain Diamonds and Prosperity Shards by crushing Deepslate Diamond Ore using Create's Crushing Wheels.

## Required Mod

- **[Mystical Agriculture](https://www.curseforge.com/minecraft/mc-mods/mystical-agriculture)**

This recipe is only available when Mystical Agriculture is installed.

## Recipe Details

| Input | Amount |
|---|---|
| ![Deepslate Diamond Ore](@minecraft:item/deepslate_diamond_ore){item} Deepslate Diamond Ore | 1 |

## Output

| Output | Amount |
|---|---|
| ![Diamond](@minecraft:item/diamond){item} Diamond | 1 |
| ![Prosperity Shard](@mysticalagriculture:prosperity_shard){item} Prosperity Shard | 3 (50% chance) |

## Processing Method

![Crushing Wheels](@create:crushing_wheel)

This recipe is processed using Create's Crushing Wheels.

Place the required ingredient into the Crushing Wheels to process it into the resulting material.


## Processing Information

- **Machine:** Crushing Wheels
- **Input:** 1x Deepslate Diamond Ore
- **Main Output:** 1x Diamond
- **Bonus Output:** 3x Prosperity Shards (50% chance)
- **Processing Time:** 200 ticks (10 seconds)
- **Required Mod:** Mystical Agriculture
