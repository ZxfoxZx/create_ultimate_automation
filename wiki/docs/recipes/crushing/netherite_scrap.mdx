
# Netherite Scrap

This recipe allows you to obtain Netherite Scrap by crushing Ancient Debris using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| ![Ancient Debris](@minecraft:item/ancient_debris){item} 1x Ancient Debris | ![Netherite Scrap](@minecraft:item/netherite_scrap){item} 1x Netherite Scrap |
| | ![Netherite Scrap](@minecraft:item/netherite_scrap){item} 1x Netherite Scrap (12% chance) |

## Processing Method

![Crushing Wheels](@create:crushing_wheel)

This recipe is processed using Create's Crushing Wheels.

Place the required ingredient into the Crushing Wheels to process it into the resulting material.


## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Ancient Debris
- **Main Output:** 1x Netherite Scrap
- **Bonus Output:** 1x Netherite Scrap (12% chance)
- **Processing Time:** 200 ticks (10 seconds)
