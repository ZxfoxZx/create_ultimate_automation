
# Netherite Scrap

This recipe allows you to obtain Netherite Scrap by crushing Ancient Debris using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| 1x Ancient Debris | 1x Netherite Scrap |
| | 1x Netherite Scrap (12% chance) |

## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Ancient Debris
- **Main Output:** 1x Netherite Scrap
- **Bonus Output:** 1x Netherite Scrap (12% chance)
- **Processing Time:** 200 ticks (10 seconds)
