
# Raw Gold

This recipe allows you to obtain Raw Gold by crushing Gold Ore using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| ![Gold Ore](@minecraft:item/gold_ore){item} 1x Gold Ore | ![Raw Gold](@minecraft:item/raw_gold){item} 1x Raw Gold |
| | ![Raw Gold](@minecraft:item/raw_gold){item} 2x Raw Gold (10% chance) |

## Processing Method

![Crushing Wheels](@create:crushing_wheel){item}

This recipe is processed using Create's Crushing Wheels.

Place the required ingredient into the Crushing Wheels to process it into the resulting material.


## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Gold Ore
- **Main Output:** 1x Raw Gold
- **Bonus Output:** 2x Raw Gold (10% chance)
- **Processing Time:** 200 ticks (10 seconds)
