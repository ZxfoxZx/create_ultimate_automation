
# Raw Silver

This recipe allows you to obtain Raw Silver by crushing Silver Ore using Create's Crushing Wheels.

## Required Mod

- **[Create: More Additions](https://www.curseforge.com/minecraft/mc-mods/create-more-additions)**

This recipe is only available when Create: More Additions is installed.

## Recipe Details

| Input | Output |
|---|---|
| ![Silver Ore](@create_more_additions:item/silver_ore) 1x Silver Ore | ![Raw Silver](@create_more_additions:item/raw_silver) 1x Raw Silver |
| | ![Raw Silver](@create_more_additions:item/raw_silver) 2x Raw Silver (10% chance) |

## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Silver Ore
- **Main Output:** 1x Raw Silver
- **Bonus Output:** 2x Raw Silver (10% chance)
- **Processing Time:** 200 ticks (10 seconds)
- **Required Mod:** Create: More Additions
