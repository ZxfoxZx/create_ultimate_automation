
# Blackstone

This recipe allows you to obtain Blackstone by crushing Basalt using Create's Crushing Wheels.

## Recipe Details

| Input | Output |
|---|---|
| ![Basalt](@minecraft:item/basalt){item} 1x Basalt | ![Blackstone](@minecraft:item/blackstone){item} 1x Blackstone |
| | ![Lapis Lazuli](@minecraft:item/lapis_lazuli){item} 1x Lapis Lazuli (20% chance) |

## Processing Information

- **Machine:** Crushing Wheels
- **Input:** Basalt
- **Main Output:** 1x Blackstone
- **Bonus Output:** 1x Lapis Lazuli (20% chance)
- **Processing Time:** 100 ticks (5 seconds)
