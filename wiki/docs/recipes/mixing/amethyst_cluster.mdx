
# Amethyst Cluster

This recipe allows you to produce Amethyst Clusters by mixing Budding Amethyst, an Amethyst Block, Slime Balls, and Amethyst Shards using Create's Mechanical Mixer.

## Recipe Details

| Input | Amount |
|---|---|
| ![Budding Amethyst](@minecraft:item/budding_amethyst) Budding Amethyst | 1 |
| ![Amethyst Block](@minecraft:item/amethyst_block) Amethyst Block | 1 |
| ![Slime Ball](@minecraft:item/slime_ball) Slime Ball | 4 |
| ![Amethyst Shard](@minecraft:item/amethyst_shard) Amethyst Shard | 4 |

## Output

| Output | Amount |
|---|---|
| ![Amethyst Cluster](@minecraft:item/amethyst_cluster) Amethyst Cluster | 1 |

## Processing Information

- **Machine:** Mechanical Mixer and Basin
- **Input:** 1x Budding Amethyst
- **Input:** 1x Amethyst Block
- **Input:** 4x Slime Balls
- **Input:** 4x Amethyst Shards
- **Output:** 1x Amethyst Cluster
- **Heat Requirement:** Heated
