
# Amethyst Cluster

This recipe allows you to produce Amethyst Clusters by mixing Budding Amethyst, an Amethyst Block, Slime Balls, and Amethyst Shards using Create's Mechanical Mixer.

## Recipe Details

| Input | Amount |
|---|---|
| ![Budding Amethyst](@minecraft:item/budding_amethyst){item} Budding Amethyst | 1 |
| ![Amethyst Block](@minecraft:item/amethyst_block){item} Amethyst Block | 1 |
| ![Slime Ball](@minecraft:item/slime_ball){item} Slime Ball | 4 |
| ![Amethyst Shard](@minecraft:item/amethyst_shard){item} Amethyst Shard | 4 |

## Output

| Output | Amount |
|---|---|
| ![Amethyst Cluster](@minecraft:item/amethyst_cluster){item} Amethyst Cluster | 1 |

## Processing Method

![Mechanical Mixer](@create:mechanical_mixer){item}

This recipe is processed using Create's Mechanical Mixer.

Place the required ingredients and fluids into a Basin and use the Mechanical Mixer to combine them into the resulting material.


## Processing Information

- **Machine:** Mechanical Mixer and Basin
- **Input:** 1x Budding Amethyst
- **Input:** 1x Amethyst Block
- **Input:** 4x Slime Balls
- **Input:** 4x Amethyst Shards
- **Output:** 1x Amethyst Cluster
- **Heat Requirement:** Heated
