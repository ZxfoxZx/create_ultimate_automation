
# Magma Cream

This recipe allows you to produce Magma Cream by milling Magma Blocks using Create's Millstone.

## Recipe Details

| Input | Amount |
|---|---|
| ![Magma Block](@minecraft:item/magma_block){item} Magma Block | 1 |

## Output

| Output | Amount |
|---|---|
| ![Magma Cream](@minecraft:item/magma_cream){item} Magma Cream | 2 |
| ![Magma Cream](@minecraft:item/magma_cream){item} Magma Cream | 1 (50% chance) |

## Processing Method

![Millstone](@create:millstone){item}

This recipe is processed using Create's Millstone.

Place the required ingredient into the Millstone to process it into the resulting material.

## Processing Information

- **Machine:** Millstone
- **Input:** 1x Magma Block
- **Main Output:** 2x Magma Cream
- **Bonus Output:** 1x Magma Cream (50% chance)
- **Processing Time:** 100 ticks (5 seconds)
