
# Netherite Upgrade Smithing Template

This recipe allows you to craft a Netherite Upgrade Smithing Template using Create's Mechanical Crafters.

## Recipe Details

| Ingredient | Amount |
|---|---|
| Netherrack | 16 |
| Diamond | 4 |
| Obsidian | 4 |
| Netherite Ingot | 1 |

## Output

| Output | Amount |
|---|---|
| Netherite Upgrade Smithing Template | 1 |

## Processing Information

- **Machine:** Mechanical Crafters
- **Pattern Size:** 5x5
- **Netherrack:** 16x
- **Diamond:** 4x
- **Obsidian:** 4x
- **Netherite Ingot:** 1x
- **Output:** 1x Netherite Upgrade Smithing Template
- **Mirrored Pattern:** Not allowed
