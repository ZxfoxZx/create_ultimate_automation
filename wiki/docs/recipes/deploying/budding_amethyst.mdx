
# Budding Amethyst

This recipe allows you to obtain Budding Amethyst by using an Axe on an Amethyst Block with Create's Deployer.

## Recipe Details

| Input | Amount |
|---|---|
| Amethyst Block | 1 |
| Axe | 1 |

## Output

| Output | Amount |
|---|---|
| Budding Amethyst | 1 |

## Processing Information

- **Machine:** Deployer
- **Input:** 1x Amethyst Block
- **Held Item:** Axe (any item matching the `c:axes` tag)
- **Output:** 1x Budding Amethyst
- **Held Item Consumption:** Axe is not consumed
