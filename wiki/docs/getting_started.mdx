
# Getting Started

Welcome to **Create: Ultimate Automation**!

Create: Ultimate Automation is a recipe-focused Minecraft mod that expands the automation and processing possibilities of the Create mod.

Rather than introducing its own machines, the mod adds new recipes that work with Create's existing machinery and processing systems.

## Requirements

Before playing, make sure you have:

- Minecraft Java Edition 1.20.1
- Minecraft Forge 1.20.1
- [Create](https://www.curseforge.com/minecraft/mc-mods/create)
- Create: Ultimate Automation

Some recipes may also require additional mods. These requirements are listed on their respective recipe pages.

## Getting Started

Once you've installed the mod and launched Minecraft, you can begin exploring its additional recipes.

The recipes are designed around Create's existing processing methods, allowing you to automate new material conversions using machinery you may already have in your factory.

## Recipe Categories

Create: Ultimate Automation currently includes recipes for the following processing methods:

- **Compacting** - Uses the Mechanical Press and Basin.
- **Crushing** - Uses Crushing Wheels.
- **Cutting** - Uses the Mechanical Saw.
- **Deploying** - Uses the Deployer.
- **Mechanical Crafter** - Uses Mechanical Crafters.
- **Milling** - Uses the Millstone.
- **Mixing** - Uses the Mechanical Mixer and Basin.
- **Smelting** - Uses furnaces and other heat-based processing methods.

Visit the [Recipes](/recipes) section to explore the available recipes.

## Tips

- Use [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) to browse available recipes in-game, if supported by your installed version.
- Experiment with Create's machinery to discover new automation possibilities.
- Check the wiki and the in-game changelog regularly for new recipes and updates.

- Use [Create: Configurable Machine Outputs](https://www.curseforge.com/minecraft/mc-mods/create-configurable-machine-outputs) to configure machine outputs.
- It's advisable to use this mod for optimal machine output configuration with Create: Ultimate Automation.
